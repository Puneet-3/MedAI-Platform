# Public research examples

These are the first test-split image in each reference class of PneumoniaMNIST-224. They were selected by dataset order, not by model success. The filenames describe benchmark reference labels; the model can disagree.

Source and attribution: MedMNIST, Jiancheng Yang and collaborators, https://zenodo.org/records/10519652 (CC BY 4.0). Exported from the published NPZ as PNG without changing pixel values. These are de-identified pediatric research images for demonstration, not images of your patients. See ../model_report/MODEL_CARD.md for model scope and results.
